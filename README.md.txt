# ColorFlow

## HEX / RGB / HSL Color Converter

ColorFlow is a web-based color conversion application that converts
between HEX, RGB, and HSL color formats.

## Features

- HEX to RGB conversion
- HEX to HSL conversion
- RGB to HEX conversion
- RGB to HSL conversion
- HSL to HEX conversion
- HSL to RGB conversion
- Color preview
- Color picker
- Input validation
- Copy conversion results
- Reset functionality

## Technologies

- HTML
- CSS
- JavaScript
